# Agent instructions for landing-page projects

Use the landing-page design skill in `.github/skills/landing-page-design/SKILL.md` whenever creating or revising landing pages, marketing pages, hero sections, pricing blocks, feature comparison pages, and product launch pages.

Prioritize:
- clear conversion goal and single primary CTA
- strong visual hierarchy and mobile-first layout
- trust signals, proof, and succinct copy
- polished typography and spacing system
- accessible contrast and motion
- design systems aligned with the product's brand and audience

Sources to consult when in doubt:
- Anthropic frontend-design plugin
- Impeccable
- UI UX Pro Max
- Astryx

Avoid generic AI patterns such as default system fonts, purple-to-blue gradients everywhere, card-in-card clutter, weak CTA hierarchy, and noisy motion.
